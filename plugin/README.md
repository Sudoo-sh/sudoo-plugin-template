# Midnight

A calm indigo theme for [Sudoo.sh](https://sudoo.sh). By day the panel keeps cool, slightly blue greys with an
indigo accent; by night it turns into a deep navy panel with a soft periwinkle accent. The logo and the accent of
the panel's e-mails match.

> This is the example theme of the Sudoo.sh plugin template, published by "Example Plugins". It is a starting point
> for your own theme, not a product.

## What changes

| | Light | Dark |
| :--- | :--- | :--- |
| Accent | Indigo `#3d4fb8` | Periwinkle `#9aa8ff` |
| Page and cards | `#f7f8fb` and white | Navy `#0b0e1a` and `#10142a` |
| Text | `#141824`, with two quieter shades | `#e6e8f2`, with two quieter shades |
| Charts | Indigo and teal | Periwinkle and light teal |
| E-mails | Indigo buttons and links | |
| Logo | A crescent moon on navy | |

Spacing, sizes and motion stay the panel's. Text keeps at least 7:1 contrast on cards in both modes, and the
panel's "more contrast" setting makes lines firmer.

## Install

Themes are plugins of the plugin manager that arrives with Sudoo.sh 2.0 (`min_sudoo_version` 2.0.0). Install
Midnight from the panel's plugin screen, then make it the panel's theme. The panel keeps following your system's
light or dark setting, or the theme switch in the sidebar.

The theme asks for no permission: it changes only how the panel looks. Uninstalling it brings the panel's own look
back; nothing else changes.
